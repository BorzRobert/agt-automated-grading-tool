# Installation

## Prerequisites
- Python 3.8 or higher
- Node.js 14 or higher
- npm or yarn

## Backend Setup

```bash
cd server
python -m venv .venv
source .venv/bin/activate  # On Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## Frontend Setup

```bash
cd frontend
npm install
```
